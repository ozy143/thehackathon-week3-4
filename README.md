# thehackathon-week3-4

## 나만의 덕질방

좋아하는 덕질 대상을 위해 3D 픽셀 방을 꾸미는 웹사이트입니다. 기본 방이 주어지고, 뽑기로 얻은 아이템으로 방을 꾸밉니다.

**배포 링크: https://thehackathon-week3-4.vercel.app**

### 실행

빌드나 설치 없이 `index.html`을 브라우저에서 열면 됩니다.

### 구성

- **기본 제공**: 3×3 장식장, 나무 침대, 책상 세트, 벽걸이 CD 플레이어
- **뽑기 카테고리**: 인테리어, 아이돌 굿즈 (캐릭터는 준비 중)
  - 카테고리마다 **기본 뽑기**(하루 1회 무료, 이후 100코인)와 **스페셜 뽑기**(300코인)가 있습니다.
  - 두 뽑기에서 나오는 항목은 같고, 스페셜 쪽이 더 화려한 디자인입니다.
- **내 방 탭**: 항목마다 가진 디자인 중 하나를 골라 방에 놓습니다.
- 코인 충전은 테스트용이며 실제 결제는 없습니다. 코인과 아이템은 브라우저(localStorage)에 저장됩니다.

### 파일

| 파일 | 내용 |
| --- | --- |
| `index.html` | 화면 구조 |
| `style.css` | 스타일 |
| `render.js` | 아이소메트릭 픽셀 렌더러 (깊이 버퍼, 외곽선) |
| `room.js` | 벽·바닥, 가구 공통 뼈대, 기본 제공 가구 |
| `items.js` | 뽑기 카테고리, 확률, 아이템 디자인 |
| `main.js` | 방 그리기, 내 방/상점 화면, 뽑기, 저장 |
