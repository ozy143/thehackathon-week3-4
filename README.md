# thehackathon-week3-4

## 픽마이돌 (PICK MY IDOL)

최애를 뽑고, 꾸미고, 친구에게 자랑하는 덕질방 웹사이트입니다. 3D 픽셀 방에 최애가 서 있고, 뽑기로 얻은 가구·굿즈·옷·음악으로 방을 꾸밉니다.

**배포 링크: https://thehackathon-week3-4.vercel.app**

### 실행

빌드나 설치 없이 `index.html`을 브라우저에서 열면 됩니다.

### 구성

- **입장**: 들어올 때마다 픽마이돌 입장 화면이 뜹니다. 처음이면 닉네임을 입력하고 최애(윈터·지젤·카리나) 중 한 명을 무료로 고릅니다. 최애는 방 가운데에 서 있습니다.
- **기본 제공**: 3×3 장식장, 나무 침대, 책상 세트, 벽걸이 CD 플레이어, 기본 옷(흰티와 반바지), 방 테마곡
- **뽑기 카테고리**: 인테리어, 캐릭터(옷), 아이돌 굿즈, 음악
  - 카테고리마다 **기본 뽑기**(하루 1회 무료, 이후 100코인)와 **스페셜 뽑기**(300코인)가 있습니다.
  - 인테리어·굿즈는 두 뽑기에서 같은 항목이 나오고 스페셜 쪽이 더 화려합니다.
  - 캐릭터: 기본 뽑기는 일상복, 스페셜 뽑기는 무대의상. 새 옷은 바로 입습니다.
  - 음악: 새 곡은 바로 CD 플레이어에 들어갑니다.
- **최애 데려오기**: 다른 캐릭터는 상점의 캐릭터 카테고리에서 800코인에 데려옵니다. 캐릭터마다 입은 옷을 따로 기억합니다.
- **탭**: 내 방(인테리어) · 굿즈 · 옷장(최애 고르기, 옷 갈아입히기) · 음악(플레이어, 내 CD) · 상점
- 방의 최애를 누르면 옷장으로, CD 플레이어를 누르면 음악이 재생·정지됩니다.
- **친구**: 머리글의 친구 버튼에서 내 친구 코드·초대 링크를 복사해 보내고, 받은 코드를 붙여 넣어 친구를 추가합니다. '놀러가기'로 친구의 방(가구·굿즈·최애·CD)을 둘러보고 친구의 음악도 들을 수 있습니다. 서버가 없어서 코드에는 '코드를 만든 순간의 방'이 담기며, 방을 새로 꾸미면 코드를 다시 보내야 합니다. 체험용 예시 친구 방도 있습니다.
- 음악은 음원 파일 없이 Web Audio로 브라우저에서 직접 연주하는 오리지널 칩튠입니다.
- 코인 충전은 테스트용이며 실제 결제는 없습니다. 코인과 아이템은 브라우저(localStorage)에 저장됩니다.

### 파일

| 파일 | 내용 |
| --- | --- |
| `index.html` | 화면 구조 |
| `style.css` | 스타일 |
| `render.js` | 아이소메트릭 픽셀 렌더러 (깊이 버퍼, 외곽선) |
| `room.js` | 벽·바닥, 가구 공통 뼈대, 기본 제공 가구 |
| `items.js` | 뽑기 카테고리, 확률, 아이템 디자인, 캐릭터·의상 목록 |
| `music.js` | 곡 데이터(악보)와 Web Audio 연주기 |
| `main.js` | 첫 방문, 방 그리기(최애·CD 포함), 각 탭 화면, 뽑기, 저장 |
| `assets/dressup/` | 캐릭터와 의상 그림 (같은 크기의 투명 PNG를 겹쳐 입힘) |
